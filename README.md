# Вещи

Тестовая галерея в виде деревянного шкафа. Девять демонстрационных предметов нарисованы в SVG, без внешних ресурсов и зависимостей.

## Запуск

Откройте `index.html` в браузере или выполните `python -m http.server 5173` из папки проекта.

## Управление

Нажмите на предмет, чтобы открыть его историю. В окне работают кнопки навигации, стрелки клавиатуры, Escape и закрытие по фону. Поддерживаются Tab, видимый фокус и настройка reduced motion.

## Свои предметы

Коллекция находится в массиве `data` в `index.html`: `title`, `meta`, `description`, `art`. Вместо SVG в `art` можно использовать HTML изображения. Тексты и даты в прототипе вымышленные.

Сайт статический; сборка не нужна. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → / (root). Публикация сайта не включена автоматически.
